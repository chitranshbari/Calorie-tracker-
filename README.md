# Calorie & Nutrition Tracker (Python)

Simple CLI tool to track calories and basic macronutrients (per day).

## Features
- Embedded nutrition dataset (about 60 common foods)
- Add foods by name and quantity (grams)
- View daily totals for calories, protein, fat, carbs
- Save a simple text log
- Add custom foods at runtime
